# MediaLens Core 1.0.0

MediaLens Core 1.0.0 is the first stable public release package for the project.

## Release focus

- A consumer-facing streaming discovery interface.
- Country, channel and platform navigation for live sources.
- Grouped watch routes through the generated watch graph.
- Internal player flow with explicit viewer start action.
- Official fallback routes when direct playback is not suitable.
- IPTV/FAST import and sync workflow for large live-channel feed sets.
- Professional public documentation and representative interface screenshots.

## Source preservation

The release keeps the existing packaged catalog and runtime bundles. The validation flow checks source preservation, direct player routes, IPTV/FAST inputs, application boot, documentation and visible interface text.

## IPTV/FAST expansion

The import workflow supports large feed sets. A full reference run processed 20,670 candidates and published 14,432 visible IPTV/FAST additions, with 15,579 total sources available after sync. These figures are operational references and can vary by feed refresh.
