# Screenshots

The `screenshots/` directory contains representative product images for the GitHub README and release page.

- `home.png` — consumer home experience with cinematic leader and discovery rails.
- `countries.png` — normalized country directory with international discovery.
- `watch.png` — watch-route selection model with player, IPTV/FAST and official fallback routes.
- `interface-references.png` — visual references derived from the project leader artwork.

The screenshots are intended to communicate the product direction clearly in the public repository.
